## All Types of Protection in Cyber Security 

 1. **Step 1: Encoding (Base64, URL Encoding, Hex):** Isko bas itna samajh lo ke data ko ek format se dusre format mein kaise badla jata hai (jaise Burp Suite mein request/response dekhte waqt iski zaroorat padti hai). Ispe zyada waqt zaya karne ki zaroorat nahi hai.

 2. **Step 2: Hashing (MD5, SHA256, Bcrypt):** Yeh samajh lo ke passwords kaise store hote hain aur inko crack kaise kiya jata hai (Hashcat / John the Ripper). Web pentesting mein iska sabse zyada use hota hai.

 3. **Step 3: Encryption (Symmetric aur Asymmetric, AES, RSA, HTTPS):** Yeh sabse critical aur bara topic hai. Isme keys, certificates, aur secure communication ka poora concept aata hai.

### Part 2: Hashing, Encryption, aur Encoding ke ilawa Protection ki Dusri Cheezein (A se Z tak detail)
Cybersecurity aur data protection mein sirf yeh teen cheezein nahi hain, balki kai aur behtareen aur powerful concepts/mechanisms bhi istemaal hote hain jo ek pentester aur developer ko pata hone chahiye:

#### 1. Salting aur Key Stretching (Passwords ke liye)
 * **Kya hai?** Yeh hashing ka hi advance roop hai. Agar sirf password ka hash banayein (jaise MD5), toh hacker "Rainbow Tables" se foran match kar leta hai. Isse bachne ke liye password ke sath kuch random characters (Salt) mila diye jate hain aur phir hash banaya jata hai. **Bcrypt** aur **Argon2** iske best examples hain jo salting aur key stretching dono use karte hain.

#### 2. Tokenization
 * **Kya hai?** Yeh sensitive data (jaise Credit Card numbers ya Personal ID numbers) ko protect karne ka tarika hai. Isme asli data ko ek secure vault mein store kar diya jata hai aur uski jagah database mein ek random string ya "Token" bhej diya jata hai. Agar hacker database chura bhi le, toh use sirf token milta hai, asli financial data nahi (yeh e-commerce websites par bohot use hota hai).

#### 3. Data Masking (Redaction)
 * **Kya hai?** Yeh data ko chupane ka ek visual tarika hai taake unauthorized log pura data na dekh sakein.
 * *Misal ke tor par:* Jab aap apna ATM card dekhte hain ya website par phone number likha hota hai, toh yeh aisi format mein hota hai: ****-****-****-4589. Isme sirf aakhri digits dikhte hain, baaki mask ho jate hain.

#### 4. Obfuscation (Code aur Binary Protection)
 * **Kya hai?** Jab koi software, mobile app (APK), ya JavaScript code banata hai, toh woh nahi chahta ke koi uske code ko asani se parh kar reverse-engineer kar le. Iske liye code ke variable names aur logic ko itna uljha diya jata hai (obfuscate kar diya jata hai) ke insaan ke liye padhna mushkil ho jata hai, jabke computer usko chala sakta hai.

#### 5. Digital Signatures aur Public Key Infrastructure (PKI)
 * **Kya hai?** Yeh ensure karta hai ke jo data ya software aapne download kiya hai, woh bilkul original hai aur raste mein kisi ne usme badlaav (tampering) nahi kiya. Yeh **Asymmetric Encryption** aur cryptographic hashing ka combination hota hai jo software updates aur official documents ki authenticity verify karne ke liye use hota hai.

#### 6. Salting / Pepper
 * **Kya hai?** Pepper ek aisi secret key hoti hai jo database ke bahar kisi alag secure location par rakhi jati hai aur password hash banate waqt usko add kiya jata hai. Agar kisi ko database mil bhi jaye, tab bhi bina Pepper ke woh kuch nahi kar sakta.
