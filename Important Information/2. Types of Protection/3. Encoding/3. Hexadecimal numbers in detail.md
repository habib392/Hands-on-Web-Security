Computer ya internet ki duniya mein **har letter ka ek fix number hota hai** (jisko ASCII code kehte hain). Jab hum kisi letter ko Hexadecimal mein convert karte hain, toh hum bas uske ASCII number ko Hex ki zuban mein likh dete hain.
Chaliye aapke naam **"Habib"** ko step-by-step Hex mein convert karke dekhte hain:

### "Habib" ki Hexadecimal Conversion
Aapke naam ke har ek letter ka Hex code yeh banta hai:
 1. **H** (Capital H) ka Hex code hai \rightarrow **48**
 2. **a** (Small a) ka Hex code hai \rightarrow **61**
 3. **b** (Small b) ka Hex code hai \rightarrow **62**
 4. **i** (Small i) ka Hex code hai \rightarrow **69**
 5. **b** (Small b) ka Hex code hai \rightarrow **62**
Toh jab poora **"Habib"** word Hexadecimal mein convert hoga, toh woh kuch is tarah dikhega:
> **48 61 62 69 62**

### Iska Asal Maqsad Kya Hai?
Aapko bas yeh samajhna hai ke jab Burp Suite ya kisi network tool mein aapko 48 61 62 69 62 likha hua nazar aaye, toh aapko foran samajh jana chahiye ke yeh kisi ne plain text mein "Habib" hi likha hai, bas usko Hex format mein badal diya hai taake system ya security filter ko parhne mein asani ho ya woh bypass ho sake.
