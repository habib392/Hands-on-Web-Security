### 1. Hexadecimal (Hex) — **Bohat Zaroori Hai!**
Web penetration testing mein aapko rozana Hexadecimal ke sath deal karna padega. Iski wajohaat yeh hain:
 * **WAF Bypass & Payload Encoding:** Jab aap kisi website par SQL Injection ya XSS ka attack karte hain aur Web Application Firewall (WAF) aapke plain text ko block kar deta hai, toh aap apne payload ko Hex format mein convert karke bhejte hain taake WAF dhoka kha jaye.
 * **Burp Suite & HTTP Traffic:** Jab aap Burp Suite mein requests dekhte hain, toh kuch parameters ya cookies Hexadecimal format mein encode hoti hain (misal ke tor par %41 ya \x41). Agar aapko Hex ki samajh nahi hogi, toh aapko pata hi nahi chalega ke data ke andar kya bheja ja raha hai.
 * **File Signatures (Magic Bytes):** Jab aap koi file upload vulnerability test karte hain aur check karna chahte hain ke file asal mein image hai ya koi malicious PHP shell, toh aap file ka pehla Hex code (FF D8 FF for JPEG ya 89 50 4E 47 for PNG) check karte hain.

#### What is Hexadecimal numbers in Detail

Computer ya internet ki duniya mein **har letter ka ek fix number hota hai** (jisko ASCII code kehte hain). Jab hum kisi letter ko Hexadecimal mein convert karte hain, toh hum bas uske ASCII number ko Hex ki zuban mein likh dete hain.
Chaliye naam **"Habib"** ko step-by-step Hex mein convert karke dekhte hain:

### "Habib" ki Hexadecimal Conversion
Aapke naam ke har ek letter ka Hex code yeh banta hai:
 1. **H** (Capital H) ka Hex code hai 👉 **48**
 2. **a** (Small a) ka Hex code hai 👉 **61**
 3. **b** (Small b) ka Hex code hai 👉 **62**
 4. **i** (Small i) ka Hex code hai 👉 **69**
 5. **b** (Small b) ka Hex code hai 👉 **62**
Toh jab poora **"Habib"** word Hexadecimal mein convert hoga, toh woh kuch is tarah dikhega:
> **48 61 62 69 62**
> 
### Iska Asal Maqsad Kya Hai?
Aapko bas yeh samajhna hai ke jab Burp Suite ya kisi network tool mein aapko 48 61 62 69 62 likha hua nazar aaye, toh aapko foran samajh jana chahiye ke yeh kisi ne plain text mein "Habib" hi likha hai, bas usko Hex format mein badal diya hai taake system ya security filter ko parhne mein asani ho ya woh bypass ho sake.
